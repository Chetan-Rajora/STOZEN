# 🚀 STOZEN

**AI-Powered Inventory Management System for Small Retailers**

---

## 📌 Vision

STOZEN helps small retailers automate inventory, sales, purchases, and business insights using Artificial Intelligence.

---

## 🛠 Tech Stack

### Mobile
- React Native (Expo)
- TypeScript

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Prisma ORM

### AI
- Python
- FastAPI
- OpenCV
- YOLO
